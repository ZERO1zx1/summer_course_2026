🎨 12 CSS өнгөний дасгал

Өнгөний төрөл, ил тод байдал, сүүдэр, градиент, контраст — жишээтэй тайлбар
#1
Нэртэй өнгө
CSS-ийн урьдчилан тодорхойлсон 140+ өнгө (жишээ нь tomato, dodgerblue).
tomato
dodgerblue
#2
Hex код (#RRGGBB)
16-тын системээр өнгө тодорхойлох. Товч (#rgb) хэлбэр бас бий.
#2d7a4a
#a44f8b
#3
RGB (0–255)
Улаан, ногоон, цэнхэр сувгуудын эрчимээр өнгө.
rgb(255,99,71)
rgb(70,130,180)
#4
RGBA (ил тод байдал)
RGB дээр alpha (0–1) нэмэгдсэн. 0 = бүрэн ил тод, 1 = бүрэн бүтэн.
rgba(255,0,0,0.3)
rgba(0,100,255,0.6)
#5
HSL (Өнгө, Ханалт, Гэрэл)
Хүний нүдэнд ойлгомжтой: hue (0–360), saturation (%), lightness (%).
hsl(200,80%,50%)
hsl(340,90%,65%)
#6
HSLA (ил тод)
HSL дээр alpha суваг нэмсэн. Ил тод байдлыг хянах.
hsla(120,70%,50%,0.4)
hsla(30,100%,60%,0.7)
#7
opacity шинж чанар
Бүх элементийн ил тод байдлыг тогтооно. RGBA нь зөвхөн дэвсгэрт нөлөөлнө.
opacity:0.5
opacity:0.5
RGBA
rgba(37,99,235,0.5)
#8
Шугаман градиент
linear-gradient() — хоёр ба түүнээс дээш өнгөний шилжилт.
90deg, #f7971e → #ffd200
#9
Радиал градиент
radial-gradient() — төвөөс цацрах өнгөний шилжилт.
circle, #a18cd1 → #fbc2eb
#10
Текст сүүдэр (text-shadow)
Текстэд өнгөт сүүдэр нэмэх. offset-x offset-y blur color
CSS өнгө
text-shadow: 3px 3px 0 #f472b6
#11
Хайрцаг сүүдэр (box-shadow)
Элементэд сүүдэр өгөх. Өнгө, бүдэгрэлт, тэлэлт тохируулна.
box-shadow: 8px 8px 0 #f97316
#12
Контраст & currentColor
Өнгөний ялгаа (унших чадвар) болон currentColor — одоогийн өнгийг дахин ашиглах.
Хар дэвсгэр дээр цагаан Шар дэвсгэр дээр хүрэн
currentColor жишээ border: 2px solid currentColor
