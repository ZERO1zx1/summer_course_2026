Дасгал 4 — Particle object-ийг унших

{
  x: 120,
  y: 75,
  size: 32,
  vx: 1.2,
  vy: -0.7,
  color: "#38bdf8"
}

Хариултууд

particle.x → 120

particle.y → 75

particle.size → 32

particle.vx → 1.2

particle.vy → -0.7

particle.color → "#38bdf8"

Дараагийн frame-ийн тооцоо

Хэрэв:

particle.x += particle.vx;
particle.y += particle.vy;

бол дараагийн frame:

x = 120 + 1.2 = 121.2

y = 75 + (-0.7) = 74.3
