Дасгал 9 — Mouse дарахад Plan-ийн өгөгдөл өөрчлөх

Хариулт

Би count property-г сонгосон. Mouse дарахад count-ийг өөрчилж, дараа нь buildScene(artPlan) дахин ажиллуулна.

function mousePressed() {
  // count-ийг 5-20 хооронд санамсаргүй өөрчилнө
  artPlan.count = random(5, 20);
  buildScene(artPlan);
}

Flow

mousePressed
    ↓
artPlan-ийн property өөрчлөгдөнө
    ↓
buildScene()
    ↓
шинэ particles үүснэ

Canvas дээр юу өөрчлөгдөж байна вэ?

→ Mouse дарах бүрд count өөрчлөгдөж, buildScene() шинэ тооны particle үүсгэнэ. Тиймээс canvas дээрх particle-ийн тоо өөрчлөгдөнө.
