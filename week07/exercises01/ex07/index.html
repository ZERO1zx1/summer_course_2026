Дасгал 7 — Хоёр өөр scene үүсгэ

Engine-ийн кодыг өөрчлөхгүй. Зөвхөн artPlan-ийг өөрчилж хоёр өөр scene үүсгэнэ.

Scene 1 — Calm

const artPlan = {
  title: "Calm",
  background: "#0a1628",
  palette: ["#67e8f9", "#38bdf8", "#a5f3fc"],
  shape: "circle",
  count: 8,
  speed: 0.8
};

• бараан background

• хөх төрлийн 3 өнгө

• circle

• цөөн particle (8)

• удаан speed (0.8)

Scene 2 — Energy

const artPlan = {
  title: "Energy",
  background: "#1a0500",
  palette: ["#ff0000", "#ff6b35", "#ffd166"],
  shape: "square",
  count: 25,
  speed: 2.8
};

• дулаан background

• улаан / улбар шар / шар palette

• square

• олон particle (25)

• хурдан speed (2.8)

Харьцуулалт

Renderer код өөрчлөгдсөн үү? → NO

Зөвхөн artPlan өгөгдөл өөрчлөгдсөн. Engine код (buildScene, updateParticle, drawParticle) бүрэн ижил.
