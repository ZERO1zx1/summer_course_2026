Дасгал 3 — buildScene()-ийг урьдчилан таа

Доорх buildScene() function-ийг судалж, асуултуудад хариулна уу.

function buildScene(plan) {
  particles = [];
  for (let i = 0; i < plan.count; i++) {
    particles.push({
      x: random(width),
      y: random(height),
      size: random(20, 55),
      vx: random(-plan.speed, plan.speed),
      vy: random(-plan.speed, plan.speed),
      color: random(plan.palette)
    });
  }
}

Асуултууд ба Хариултууд

1. count: 5 бол particles.length = ______

→ 5

Тайлбар: for loop нь i = 0-ээс i < 5 хүртэл 5 удаа ажиллаж, 5 particle push хийнэ.

2. count: 20 бол particles.length = ______

→ 20

Тайлбар: for loop нь i = 0-ээс i < 20 хүртэл 20 удаа ажиллаж, 20 particle push хийнэ.

3. speed: 0 бол vx = ______, vy = ______

→ vx = 0, vy = 0

Тайлбар: random(-0, 0) нь үргэлж 0 буцаана. Тиймээс particle хөдөлдөггүй.

4. speed: 3 бол vx ямар range-аас утга авах вэ? ______ - ______

→ -3 - 3

Тайлбар: random(-3, 3) нь -3-аас 3 хүртэлх утга авах боломжтой.

5. Яагаад function-ийн эхэнд particles = []; гэж бичсэн бэ?

→ Хуучин particle-уудыг устгаж, шинэ scene-ийг цэвэрхэн эхлүүлэхэд зориулагдсан.

Тайлбар: Хэрэв particles = [] гэж бичихгүй бол, өмнөх buildScene() дуудлагаас үлдсэн particle-ууд шинэ particle-уудтай нийлж, тоо нь давхардана.
