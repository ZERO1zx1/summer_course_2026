Дасгал 1 — Object-ийн утгыг унших

const artPlan = {
  title: "Ocean Calm",
  background: "#081a2b",
  palette: ["#67e8f9", "#38bdf8", "#a5f3fc"],
  shape: "circle",
  count: 12,
  speed: 1.5
};

Хариултууд

artPlan.title → "Ocean Calm"

artPlan.background → "#081a2b"

artPlan.palette[0] → "#67e8f9"

artPlan.palette[1] → "#38bdf8"

artPlan.palette[2] → "#a5f3fc"

artPlan.shape → "circle"

artPlan.count → 12

artPlan.speed → 1.5

Асуултууд

1. palette ямар data type вэ? → Array (массив)

2. artPlan ямар data type вэ? → Object (объект)

3. count number уу string үү? → Number (тоо)

4. "circle" number уу string үү? → String (мөр)
