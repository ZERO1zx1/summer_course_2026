Дасгал 8 — Mouse дарахад scene reset хийх

Хариулт

function mousePressed() {
  buildScene(artPlan);
}

Шалгах

• particle-ийн байрлал өөрчлөгдөнө ✓

• size өөрчлөгдөж болно ✓

• color өөрчлөгдөж болно ✓

• particle-ийн тоо өөрчлөгдөхгүй ✓

Асуулт

Яагаад particle-ийн тоо хэвээр үлдэж байна вэ?

→ Учир нь buildScene(artPlan) нь plan.count-ийн утгаар л particle үүсгэдэг. artPlan.count өөрчлөгдөөгүй тул ижил тооны particle үүснэ. Зөвхөн байрлал, size, color нь random()-оор шинэ утга авдаг.
