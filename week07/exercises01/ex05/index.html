Дасгал 5 — Debug: Яагаад particle хөдөлсөнгүй вэ?

Алдаатай код

function updateParticle(particle) {
  particle.x + particle.vx;
  particle.y + particle.vy;
}

Хариултууд

1. Алдаатай хоёр мөр:

→ particle.x + particle.vx; — үр дүнг хадгалахгүй байна

→ particle.y + particle.vy; — үр дүнг хадгалахгүй байна

2. Зөв хувилбар:

function updateParticle(particle) {
  particle.x += particle.vx;
  particle.y += particle.vy;
}

3. Яагаад анхны код хөдөлгөөн үүсгээгүй вэ?

→ Тооцоолсон шинэ утга нь property-д буцааж хадгалагдахгүй байгаа тул particle-ийн x, y утга өөрчлөгдөхгүй.
