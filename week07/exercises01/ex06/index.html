Дасгал 6 — Shape Renderer

function drawParticle(particle, shape) {
  noStroke();
  fill(particle.color);
  if (shape === "square") {
    rectMode(CENTER);
    square(particle.x, particle.y, particle.size);
  } else {
    circle(particle.x, particle.y, particle.size);
  }
}

Гаралтууд

Plan A — shape: "circle"

→ Дугуй (circle) зурна

Plan B — shape: "square"

→ Дөрвөлжин (square) зурна

Plan C — shape: "triangle"

→ Дугуй (circle) зурна — else хэсэг ажиллана

Асуулт

Яагаад "triangle" үед error гарахгүй байгаа вэ?

→ Учир нь if (shape === "square") нь зөвхөн "square" үед шалгагдана. Бусад бүх утга (triangle, circle, бусад) нь else хэсэгт орж circle() зурна. Тиймээс error гарахгүй, зүгээр л дугуй зурна.
