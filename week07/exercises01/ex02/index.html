Дасгал 2 — Plan-ийг өөрчил

Engine-ийн бусад кодыг өөрчлөхгүйгээр зөвхөн artPlan-ийг өөрчилнө.

Дүрэм: Энэ дасгалд зөвхөн artPlan-ийг өөрчилнө. Engine код өөрчлөгдөхгүй.

Шинэ artPlan (өөрчилсөн)

const artPlan = {
  title: "Desert Sunset",
  background: "#2d1b00",
  palette: ["#ff6b35", "#ffd166", "#f4a261"],
  shape: "square",
  count: 15,
  speed: 2.2
};

Өөрчлөлтүүд

• title: "Ocean Calm" → "Desert Sunset"

• background: "#081a2b" → "#2d1b00" (дулаан бараан)

• palette: 3 шинэ өнгө → ["#ff6b35", "#ffd166", "#f4a261"] (улбар шар/шар)

• shape: "circle" → "square"

• count: 12 → 15 (5–20 хооронд)

• speed: 1.5 → 2.2 (0.5–3 хооронд)
