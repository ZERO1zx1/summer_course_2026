Би 16 настай, технологи болон кодчиллоор дамжуулж шинэ зүйл бүтээх сонирхолтой залуу хөгжүүлэгч байна.

💻 Миний кодчиллын аялал

Би анх Python хэлнээс гараагаа эхэлж, дундаж түвшин хүртэл суралцсан. Энэ хугацаандаа өөрийн сонирхлоор хэд хэдэн Discord сервер болон ботуудыг хөгжүүлж байсан туршлагатай.

Одоогийн байдлаар би вэб хөгжүүлэлт (Web Development) рүү шимтэн орж, дараах технологиудыг идэвхтэй суралцаж байна:

  • HTML5 - Вэбсайтын бүтэц гаргах
  • CSS3 - Вэбсайтыг загварчилж, өнгө үзэмж оруулах
  • JavaScript - Вэбсайтыг илүү амьд, интерактив болгох

⚔️ Дуртай зүйлс & Хобби

Код бичихээс гадна чөлөөт цагаараа аниме үзэх дуртай. Миний хамгийн дуртай дүр бол Demon Slayer аниме-гийн илдний дархан Hotaru Haganezuka.

"Хаганэзука илдээ давтахдаа хамаг анхаарлаа төвлөрүүлж, тууштай зүтгэдэг шиг би ч гэсэн код бүрээ төгс, цэвэрхэн бичихийг хичээдэг."
